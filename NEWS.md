# instarreport 1.0.0

* Initial CRAN submission.

* Version numbering tracks the INSTAR framework: this release implements
  INSTAR v1.0, the item set described in White et al. Sheets written by
  `write_template()` and `write_report()` record the framework version
  they were completed against, and `read_instar()` warns when a corpus
  mixes versions.
