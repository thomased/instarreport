# Rendering attributes for a single item

Rendering attributes for a single item

## Usage

``` r
.render_attrs(value, status)
```

## Arguments

- value:

  Character; substantive content, or `NA`.

- status:

  One of
  [.STATUS_LEVELS](https://instar-statement.org/reference/dot-STATUS_LEVELS.md).

## Value

A list with `display`, `colour`, and `face`.
