# Reserved item id carrying the usage note

A single row at the top of the fillable CSV explaining the file's
conventions. It travels with the file, so someone handed the sheet by a
co-author, or pulling it out of a repository years later, does not need
the paper open to know what a blank cell means.
[`read_items()`](https://instar-statement.org/reference/read_items.md)
drops it.

## Usage

``` r
.HELP_FIELDS
```
