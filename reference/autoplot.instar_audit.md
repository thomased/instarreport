# Return an audit's figure as a plot object

Return an audit's figure as a plot object

## Usage

``` r
# S3 method for class 'instar_audit'
autoplot(object, by = NULL, ...)
```

## Arguments

- object:

  An `instar_audit`.

- by:

  Optional study-level column to facet by.

- ...:

  Unused.

## Value

A ggplot object.
