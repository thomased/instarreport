## Notes

The only note is the standard new-submission note, which also flags four
words in the DESCRIPTION as possibly misspelled. All four are correct:

* "INvertebrate" is capitalised this way because INSTAR is an acronym of
  INvertebrate Standards for Treatment And Reporting, and the DESCRIPTION
  expands it to show where the letters come from.
* "PRISMA" is the name of an established reporting guideline
  (Preferred Reporting Items for Systematic Reviews and Meta-Analyses).
* "et" and "al" are part of the citation "White et al., in prep".

The reference in the DESCRIPTION has no DOI because the manuscript
describing the framework is not yet published. We will add it in the
form Authors (Year) <doi:...> as soon as it is available.
